> **Lumora** adalah ekosistem digital inovatif yang dirancang khusus untuk para pelaku industri kreatif. Kami menghubungkan talenta terbaik—mulai dari desainer logo, ilustrator, hingga editor video—dengan klien yang mencari karya berkualitas tinggi, melalui antarmuka yang modern, cepat, dan elegan.

---

## 🚀 Fitur Unggulan

💎 **Estetika Premium & Minimalis**  
Antarmuka yang bersih, elegan, dan *fully responsive* yang mengutamakan karya kreator. Dibangun dengan Tailwind CSS untuk memberikan micro-interactions dan efek glassmorphism yang *smooth*.

🎨 **Galeri Karya Kreatif (Creator Feeds)**  
Jelajahi inspirasi visual tanpa batas. Sistem grid portofolio yang dinamis memungkinkan desainer untuk memamerkan karya terbaik mereka kepada calon klien.

🔎 **Katalog Layanan Cerdas (Explore)**  
Sistem pencarian dan filter kategori yang intuitif untuk mempermudah klien menemukan jasa kreatif yang spesifik—dari Desain Grafis, Video Editing, hingga Voice Over.

⚡ **Performa Kilat dengan Next.js App Router**  
Didukung oleh arsitektur terbaru Next.js untuk waktu muat halaman yang instan, optimasi SEO yang mendalam, dan pengalaman pengguna yang mulus tanpa *lag*.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Bahasa Pemrograman**: [TypeScript](https://www.typescriptlang.org/)
- **Ikonografi**: [Lucide React](https://lucide.dev/)
- **Animasi & Interaksi**: CSS Transitions & Swiper.js

## 💻 Panduan Instalasi & Pengembangan

Ikuti langkah-langkah di bawah ini untuk menjalankan Lumora di mesin lokal Anda:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/akirausethis/LUMORA.git
   cd LUMORA
   ```

2. **Instal dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```

4. **Buka di browser:**
   Akses `http://localhost:3000` untuk melihat aplikasi berjalan.
